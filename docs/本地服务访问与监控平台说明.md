## 二、监控与部署平台说明

### 2.1 Prometheus（http://localhost:9090）

**指标采集与时序数据库**，是监控体系的数据源头。

- 按配置周期性抓取各服务的 `/metrics` 端点，写入本地时序库（TSDB）。
- 当前抓取 7 个目标：智能问数应用（`:3000/metrics`）、宿主机 node-exporter、MySQL exporter、Redis exporter、Alertmanager 自身，以及跨项目的 AIOps 生产 BFF/worker（TLS + basic auth）。
- 数据保留策略：30 天 / 2GB 上限。
- 按 `prometheus-alerts.yml`、`aiops-demo-rules.yml` 中的规则持续评估，触发后把告警推送给 Alertmanager（9093）。
- 本身只做存储与查询，不做可视化，通常配合 Grafana 使用。

### 2.2 Grafana（http://localhost:3100）

**可视化与仪表盘平台**，是监控的展示层。

- 把 Prometheus 的时序数据渲染成图表、看板，支持多数据源聚合。
- 本栈已自动配置 Prometheus 数据源，仪表盘从 `deploy/grafana/dashboards` 自动加载（含 AIOps 概览面板）。
- 启用 `--profile loki` 后还会自动挂载 Loki 日志数据源，实现指标 + 日志联动排查。
- 本身不采集数据，只查询和展示；告警规则仍在 Prometheus / Alertmanager 侧。

### 2.3 Coolify（http://localhost:8000）

**开源自托管 PaaS 平台**，相当于私有化的 Vercel / Heroku。

- 从 Git 仓库构建并部署应用，管理环境变量、域名、HTTPS 证书。
- 内置数据库与服务的"一键创建"（PostgreSQL、MySQL、Redis 等）。
- 提供实时日志、部署回滚、定时任务、备份等运维能力。
- 当前本机这套（app + postgres + redis + realtime 共 4 容器）处于运行状态，但近 24 小时无实际访问，属于备用工具。

## 四、安全提示

1. **Grafana 建议立即改密码**：当前为默认 `admin/admin`，且端口绑定在 `0.0.0.0`，局域网内任何设备都能用默认口令登录。修改入口：右上角头像 → Profile → Change password。
2. **Prometheus / Alertmanager 无认证**且对局域网开放，任何设备可读取全部指标、查看甚至静默告警。若后续收紧端口，这两处应优先改为 `127.0.0.1` 绑定。
3. Coolify 当前允许注册（`IS_REGISTRATION_ENABLED=true`），对局域网开放时可考虑关闭注册。
4. Coolify 忘记密码时可在容器内重置：

   ```bash
   docker exec -it coolify php artisan tinker
   # 在 tinker 中执行：
   # $u = App\Models\User::where('email','dgjin@qq.com')->first();
   # $u->password = Hash::make('新密码'); $u->save();
   ```
